# 2. Project Objectives

## 2.1 Primary Objective

The primary objective of **Kinetra** is to develop a data-driven personalized movement and wellness system that analyzes relevant individual and pain-related characteristics and uses the resulting insights to provide personalized exercise and wellness guidance.

---

## 2.2 Supporting Objectives

To achieve the primary objective, the project will pursue the following objectives:

### 1. Understand the Problem and Available Data

Identify the relevant characteristics, factors, and information required to understand individual movement and pain-related profiles.

### 2. Collect and Prepare Data

Identify suitable data sources and develop a process for collecting, cleaning, transforming, and preparing data for analysis.

### 3. Perform Exploratory Data Analysis

Use statistical summaries and visualizations to understand the structure, distribution, and patterns present in the data.

### 4. Apply Statistical Analysis

Investigate relationships and patterns between relevant variables using appropriate statistical techniques.

### 5. Develop Predictive Approaches

Explore suitable predictive models for identifying meaningful user profiles or outcomes based on available data.

The exact prediction target will be determined after the data has been understood and prepared.

### 6. Explore User Profiles

Investigate whether meaningful groups or patterns can be identified among individuals using appropriate unsupervised learning techniques.

### 7. Develop Personalized Recommendations

Use analytical findings and, where appropriate, predictive models to develop a mechanism for providing personalized exercise and wellness guidance.

### 8. Provide Safety-Oriented Guidance

Incorporate appropriate safety considerations, precautions, and clear boundaries into the recommendation process.

### 9. Evaluate the Developed Approaches

Evaluate analytical models and recommendation approaches using appropriate performance and evaluation measures.

### 10. Develop an Application

Progressively transform the developed Data Science workflow into a usable application that presents relevant information and personalized guidance to users.

### 11. Explore Advanced Movement Analysis

As an advanced extension, investigate the possibility of using computer vision and pose-estimation techniques to analyze exercise movement and provide feedback on exercise form.

---

## 2.3 Data Science Learning Objectives

Since Kinetra is being developed as part of the **Fundamentals of Data Science** course, the project will also provide an opportunity to apply concepts learned throughout the semester.

The project is expected to explore:

* Data Science processes and roles
* Descriptive, diagnostic, predictive, and prescriptive analytics
* Data collection and preparation
* Probability and statistics
* Exploratory Data Analysis
* Data visualization
* Feature engineering
* Supervised learning
* Unsupervised learning
* Dimensionality reduction
* Association rule mining
* Anomaly detection
* Recommendation systems
* Model evaluation
* DataOps and introductory MLOps concepts

These techniques will be incorporated where they have a meaningful connection to the project and where the available data supports their use.

---

## 2.4 Expected Outcome

By the end of the project, Kinetra aims to demonstrate a complete Data Science workflow, progressing from problem understanding and data preparation to analysis, modeling, evaluation, personalization, and application development.

The final system is expected to demonstrate how multiple Data Science concepts can be integrated into a single real-world problem rather than being implemented as isolated techniques.
